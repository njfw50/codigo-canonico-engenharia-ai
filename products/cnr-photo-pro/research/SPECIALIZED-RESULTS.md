# CNR specialist-library development diagnostic
2026-11-25. Author-directed experimental research; not production, certification, or approval. No commercial UI or release gate modified. Existing integrated_engine, TextureGuard and OpticalGuard unchanged. Runtime adapters are not canonical core dependencies. No purchases.

## Methods
Two separate alternatives on the same 14 references x 3 noise levels x 3 seeds, max side 256, blur 1.2, as validate_integration.py. New Haar diagonal MAD noise proxy, scikit-image NLM (patch 5, distance 3, h=.8*sigma), or OpenCV colored NLM (template 5, search 11, h and hColor=.8*sigma*255), then bounded noise-dependent luminance accent. No reference image used by processor. Source immutability and no source return checked for all 252 attempts. Existing guards executed without weakening. Parameters selected for development, not holdout. PyWavelets unavailable, hence estimate_sigma and wavelet denoising were NOT executed; initial slower settings timed out, discarded, then completed final comparison. No libvips or paid SDK used. The comment mentioning wavelet shrinkage in the tested adapter is inaccurate: actual alternatives are NLM and colored NLM. OpenCV thread setting is global; research only. Input geometry minimum, saturated noise estimate, and runtime performance require additional review.

Clipping rejection must be diagnosed rather than bypassed. No claim all faults solved.
