# Canonical AI Control — privacy disclosure (pre-release draft)

This open-source, pre-release integration is designed to serve public canonical text from a pinned public GitHub commit. In its current public, read-only configuration it does not ask users to create accounts and does not persist agent policy profiles.

Requests to the hosting service may generate routine service logs (such as timestamp, endpoint, error and network information) under the hosting provider's own retention and security terms. No prompts, microphone recordings, camera footage, or device location are required to consult the canonical source. Future authenticated write features are intentionally not released until their data processing, retention, erasure, storage, and security arrangements are specified and implemented.

This draft describes the submitted code, not a claim that a production service has been deployed or reviewed. For questions or security reports, use GitHub Issues at https://github.com/njfw50/codigo-canonico-engenharia-ai/issues.
