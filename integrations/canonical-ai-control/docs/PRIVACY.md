# Privacy Policy — Canonical AI Control
Effective: 2026-11-15

**Operator:** Michel Silva de Souza. Project: https://github.com/njfw50/codigo-canonico-engenharia-ai

## Data collected
The public read-only MCP connector is intended only to retrieve the 25 public canonical texts from the pinned GitHub revision. It requires no ChatGPT conversation transcripts, account credentials, device location, microphone, camera, or file access. The application does not persist per-user profiles or permission configurations in this hosted read-only mode.

The hosting provider Vercel may process standard connection metadata such as IP addresses, request paths, timestamps, and error information for delivery, security, and operational logging, according to Vercel's service practices. Queries sent to the MCP endpoint pass through the hosting infrastructure to answer the request.

## Sharing and retention
The connector fetches original public law files from GitHub to answer explicit tool calls. It does not sell personal data. The app itself does not maintain a user activity database; operational logs, if any, are controlled by the hosting provider. We do not warrant deletion of provider-held logs through a plugin control.

## Controls and contact
You can uninstall or disconnect this plugin in ChatGPT. For privacy requests and security concerns, open a private issue if supported or a regular issue without sensitive details at https://github.com/njfw50/codigo-canonico-engenharia-ai/issues.

This policy describes the read-only hosted preview. Future authenticated agent-control releases will require a published update before collecting and persisting user policy data.
